# Пакет для магазина (черновик)

## Google Play listing

**Название:** Musico — музыкальный плеер  
**Краткое описание:** Слушайте каталог, собирайте плейлисты и находите концертные площадки рядом.  
**Полное описание:** Musico объединяет музыкальный каталог, поиск по трекам, избранное, историю прослушивания и собственные плейлисты. Сохраняйте каталог для офлайн-просмотра и находите концертные площадки на карте. Для синхронизации библиотеки войдите через email или Google после настройки провайдера.

Перед отправкой подтвердить реальные возможности сервера, права на аудиозаписи и изображения, добавить скриншоты приложения и заменить учебный Android package id на namespace владельца.

## Политика конфиденциальности — проект текста

Musico использует Supabase для регистрации и входа, хранения имени и настроек профиля, плейлистов, избранного и истории прослушиваний. Эти данные синхронизируются между устройствами, где пользователь вошёл в свой аккаунт.

Экран площадок запрашивает геопозицию только после нажатия пользователем кнопки определения местоположения. Приложение использует её для перемещения камеры карты и не сохраняет координаты на сервере.

Если пользователь включает переключение трека встряхиванием, приложение анализирует показания акселерометра на устройстве. Сырые показания датчика не сохраняются и не передаются на сервер.

Для диагностики необработанных ошибок приложение отправляет в Supabase тип ошибки, платформу и постоянное общее сообщение. Произвольный текст исключения и stack trace не отправляются. Отчёт связывается с аккаунтом, если пользователь вошёл. При удалении профиля идентификатор в отчёте очищается.

Supabase и Google Maps обрабатывают данные согласно своим условиям и политикам. В приложении нет оплаты и рекламы. Запросы на удаление аккаунта и связанных данных следует направлять разработчику: **[добавить контакт владельца]**. Поставщик сервиса: **[добавить юридическое имя/адрес]**. Дата действия политики: **[добавить дату]**.

Этот текст — заготовка, а не опубликованная юридическая политика. Заполнить контакты, проверить настройки хранения/удаления в Supabase, добавить публичный URL политики и сверить декларацию Data Safety перед отправкой.
